# Brand Design Guidelines

## Overview

Guidelines for authoring emails and signatures that reflect the client's visual identity.

## Visual Rules

- **Logo Usage**: Maintain 160x40px aspect ratio. Ensure at least 15px safe padding around the logo.
- **Button Conventions**: Always use solid primary color for primary actions. Use 6px border-radius.
- **Spacing Scale**:
  - Section vertical padding: 24px - 32px
  - Content block separation: 16px
  - Small text / disclaimer margins: 8px - 12px
- **Contrast Ratios**: Body text (`#0f172a` on `#ffffff`) meets WCAG AAA standards. Secondary text (`#64748b`) meets WCAG AA standards.
