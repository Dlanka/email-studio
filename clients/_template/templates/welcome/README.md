# Welcome Email Template

## Purpose

Sent immediately to newly registered users to welcome them, highlight key value propositions, and guide them through their initial 3 onboarding steps.

## Dynamic Placeholders

- User First Name (`Alex`)
- Primary CTA Destination (`https://example.com/dashboard`)
- Support links

## Compatibility Notes

- Responsive layout stacks cards into a single column on viewports under 480px.
- Tested across Apple Mail, Gmail, Outlook for Web, and Outlook 2016+.
