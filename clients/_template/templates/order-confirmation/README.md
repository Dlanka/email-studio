# Order Confirmation Email Template

## Purpose

Transaction receipt sent immediately upon successful checkout. Provides order summary, shipping address, payment method, line item pricing breakdown, and tracking link.

## Dynamic Placeholders

- Order ID (`ORD-89412`)
- Customer Name (`Morgan`)
- Shipping & Billing Address
- Line items (Name, options, qty, price)
- Total calculations (Subtotal, Shipping, Tax, Total)
- Tracking URL
